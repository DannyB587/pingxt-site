Simple workflow

From quick checks to live monitoring.

Use normal mode for breadth. Use Watch Mode when you need a focused, live view of the endpoints that matter.

Normal Mode

Check several hosts, a subnet, an address range, or a saved target list.

pingxt 8.8.8.8 9.9.9.9
pingxt 192.168.1.0/24
pingxt 192.168.1.10-192.168.1.50
pingxt -f targets.txt

Watch Mode

Keep a curated set of important endpoints visible during changes or troubleshooting.

pingxt -watch -f core.txt
pingxt -watch -workers 64 -t 500ms -f lan.txt

FAQ

Quick answers.

Is PingXT a network scanner?

PingXT is a focused ICMP reachability utility. It can test CIDR networks and ranges, but it is not a vulnerability scanner, asset-management platform, or full Network Monitoring System.

What is Watch Mode for?

Watch Mode is best for a curated set of important devices—routers, switches, gateways, servers, WAN endpoints, or lab nodes—during maintenance and troubleshooting.

Why can a reachable device show DOWN?

PingXT measures ICMP reachability. Firewalls, ACLs, routing conditions, filtering, rate limiting, host configuration, or an aggressive timeout can prevent an Echo Reply even when the device provides other services.

Does one license cover several computers?

The planned PingXT 1.0 license is per user rather than per machine. Final terms will be published with the commercial release after legal review.

Will there be a subscription?

No software subscription is planned for PingXT 1.0. The launch model is a $19.99 one-time purchase with PingXT 1.x updates included.

Which Windows terminal should I use?

Windows Terminal is recommended for the smoothest Watch Mode experience. Classic Command Prompt has more limited terminal rendering behavior.
